\begin{abstract}
Addition formulas for the cosine, sine, and tangent functions.
\end{abstract}
\maketitle

It is tempting to think
\[
  \cos(\theta_1 + \theta_2) = \cos\theta_1+ \cos\theta_2
\]
and that
\[
 \sin(\theta_1 + \theta_2) = \sin\theta_1+ \sin\theta_2.
\]
Show both of these equations are false by choosing \emph{specific} values for $\theta_1$ and $\theta_2$. Make simple choices.
\begin{freeResponse}
\end{freeResponse}


We now use vectors to find the correct expressions for $\cos(\theta_1 + \theta_2)$ and $ \sin(\theta_1 + \theta_2)$.

\begin{example} \label{Qd2fr4fds3}


Let points $P_1$, $P_2$ on the unit circle have respective polar angles $\theta_1$, $\theta_1 +\theta_2$ as shown below.

\begin{enumerate}
\item Then $P_1$ has coordinates
\[
  (x_1, y_1) = (\answer{\cos\theta_1}, \answer{\sin\theta_1} )
\]
and $P_2$ coordinates
\[
 (x_1, y_1) = (\answer{\cos(\theta_1+\theta_2)}, \answer{\sin(\theta_1+\theta_2} ).
\]
\end{enumerate}
\end{example}
